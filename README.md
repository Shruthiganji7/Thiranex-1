Student Performance Analysis

Project Overview
This project focuses on cleaning, analyzing, and visualizing a Student Performance dataset using Python in Google Colab. The project demonstrates data preprocessing, exploratory data analysis, and storytelling with data through various visualizations and dashboards.

Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

Features
- Missing value analysis
- Duplicate value checking
- Outlier detection using IQR method
- Data visualization
- Dashboard creation
- Insight generation

Dataset Information
The dataset contains student-related information such as:
- Age
- Gender
- Study Hours
- Attendance Percentage
- Subject Scores
- Final Percentage
- Performance Level

Key Insights
- Students with higher study hours performed better academically.
- Attendance percentage positively influenced final scores.
- Strong correlation exists between subject scores.
- Parental education impacted student performance.

Files Included
- Student_Performance_Analysis.ipynb
- Cleaned_Student_Performance.csv

Conclusion

This project helped in understanding data preprocessing, visualization, and storytelling using Python libraries such as Pandas, Matplotlib, and Seaborn.
